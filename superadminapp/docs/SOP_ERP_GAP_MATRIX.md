## 1. Classification Definitions

In strict accordance with the Phase SOP-01 Evidence Rules, only the following classifications are utilized:
- **`IMPLEMENTED`**: Fully evidenced in both active UI components, backend Express routes, and database models with verifiable operational linkage.
- **`PARTIALLY IMPLEMENTED`**: Capabilities exist in the backend data models or standalone apps, but lack complete SuperAdminApp workspace UI, automated triggers, or cross-domain handoffs.
- **`MISSING`**: Specific client operational procedure, calculation, alarm, or form not present in the codebase.
- **`NEEDS CLIENT CLARIFICATION`**: Ambiguity in business rules, formulas, threshold parameters, or departmental role responsibilities.
- **`NOT VERIFIED`**: Capability exists in code but runtime verification could not be performed under read-only constraints.
