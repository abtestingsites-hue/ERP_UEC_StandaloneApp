# ERP UEC Standalone Apps

This repository contains the standalone application modules for the ERP UEC ecosystem:

- **CRMApp**: Customer Relationship Management and inquiries portal
- **FinanceBillingApp**: Billing, invoices, receipts, and finance management
- **Frontend**: Unified frontend client application
- **HomeCareApp**: Home care operations, patient care schedules, and assessments
- **HRApp**: HR management, staff directory, attendance, and payroll governance
- **InventoryApp**: Stock management, procurement, GRN receiving, and vendor directory
- **MobileApp**: Mobile interface and portable workflows
- **superadminapp**: Central superadmin console, executive reports, and cross-domain controls
- **UNCFDonationsApp**: UNCF donation tracking, receipts, and campaign management
- **VisitorApp**: Gate management, visitor passes, security logs, and vehicle check-in/out
